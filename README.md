# Guilherme Vital

### Analista de Dados & BI | Planejamento e Supply Chain

Trabalho entre o comercial, a logística e a produção de uma indústria de insumos agrícolas em Uberaba, MG. Construo painéis, automações em Python e ferramentas de decisão que rodam em produção todos os dias: do pedido ao caminhão, da matéria-prima ao e-mail da sexta-feira.

Antes dos dados, foram mais de 4 anos na operação logística, rastreando cargas de risco e liberando caminhões na expedição. Por isso gosto de soluções que falam a língua de quem está no pátio e de quem está na reunião.

**[Veja o portfólio com demonstrações interativas →](https://guilhermeov.github.io/portfolio/)**

---

#### O que eu construo

- Rotinas em Python que leem o ERP e atualizam painéis e planilhas do time de hora em hora
- Painéis em HTML, CSS e JavaScript e em Power BI para planejamento, logística e comercial
- Previsão de risco de chuva para programação de cargas, combinando 3 modelos meteorológicos
- Explosão de consumo de matéria-prima com simulação de pedidos
- Apps em Power Apps e SharePoint para processos do comercial e do planejamento

#### Stack

Python (pandas, openpyxl) · SQL · Power BI · DAX · Power Query · Power Apps · SharePoint · HTML · CSS · JavaScript · SVG · Protheus/TOTVS

#### Formação

Sistemas de Informação, Uniube (conclusão prevista em dez/2026) · Inglês intermediário
